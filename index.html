PANDUAN RESMI TERBARU

Cara Membuat Roblox Open Cloud API Key (User & Group)

Buka Roblox Creator Hub
1
Pastikan Akun Pribadi di Kiri Atas
Buka create.roblox.com. Di bawah logo ROBLOX CREATOR (pojok kiri atas), pastikan nama akun profil pribadi Anda yang terpilih (contoh: Feyhams ∨).
2
Klik "... All tools" ➔ "API Keys"
Di menu samping kiri, klik tombol "... All tools". Pada jendela panel yang muncul, di bawah kolom Creations, klik "API Keys" (di atas OAuth 2.0 apps).
3
Klik "Create API Key"
Klik tombol biru "Create API Key" di kanan atas. Isi kolom Name bebas (contoh: FH Audio User).
4
Izin Assets (Wajib)
Di Access Permissions, klik "Add API System" / "Select API System" ➔ pilih Assets. Centang kedua izin berikut:
✓ asset:read ✓ asset:write
5
IP Security & Salin Kunci
Di Security / IP Restrictions, pilih No IP Restrictions (atau masukkan 0.0.0.0/0) agar request upload web tidak diblokir. Klik "Save & Generate Key" lalu langsung Salin (Copy) kodenya.
6
Simpan ke FH Audio
Klik + Add account di atas ➔ Creator Type: User ID ➔ Masukkan ID dari URL profil Anda (roblox.com/users/[ID]/profile) dan tempelkan API Key!
1
GANTI DROPDOWN PROFIL KE GROUP
Buka create.roblox.com. Di bawah logo ROBLOX CREATOR (pojok kiri atas), klik dropdown akun Anda (contoh: Feyhams ∨) ➔ PILIH NAMA GROUP ANDA. Halaman akan beralih ke dashboard Group tersebut!
2
Klik "... All tools" ➔ "API Keys"
Di menu samping kiri, klik "... All tools". Pada jendela panel yang muncul, di bawah kolom Creations, klik "API Keys".
3
Klik "Create API Key"
Klik tombol biru "Create API Key". Beri nama bebas (contoh: FH Audio Group). (Catatan: Akun Anda harus Owner Group atau Admin dengan hak akses Open Cloud).
4
Izin Assets (Wajib)
Di Access Permissions, klik "Add API System" / "Select API System" ➔ pilih Assets. Centang kedua izin:
✓ asset:read ✓ asset:write
5
IP Security & Salin Kunci
Di Security / IP Restrictions, pilih No IP Restrictions (atau masukkan 0.0.0.0/0). Klik "Save & Generate Key" lalu langsung Salin (Copy) kodenya.
6
Simpan ke FH Audio
Klik + Add account di atas ➔ Creator Type: Group ID ➔ Masukkan ID dari URL group Anda (roblox.com/groups/[ID]/...) dan tempelkan API Key!
💡
Cara Mengetahui Target ID Anda di Roblox: • User ID: Buka profil Roblox Anda di browser ➔ lihat link URL: roblox.com/users/283131443/profile (angka tersebut adalah User ID). • Group ID: Buka halaman Group Anda di browser ➔ lihat link URL: roblox.com/groups/12345678/Nama-Group (angka tersebut adalah Group ID). • Penting: Pastikan memilih "No IP Restrictions" saat membuat API Key agar pengunggahan audio dari browser/web hosting tidak terblokir firewall IP Roblox.
